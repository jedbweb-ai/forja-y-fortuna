# Arte

- `originales/`: lo que sale de ChatGPT, tal cual (por tipo: personajes, monstruos, iconos...). Sirve para volver a procesar si cambia la guía.
- El arte ya procesado va en `src/assets/arte/<carpeta>/<clave>.png` y el juego lo carga solo.

Herramienta para preparar cada imagen (con `npm run dev` corriendo): http://localhost:5173/herramientas/arte.html

Estilo, medidas, paleta y pedidos: `docs/GUIA_DE_ARTE.md`.
